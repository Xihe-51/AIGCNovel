## 1. 模板中心

### 1.1 后端

- 新增 `GET /project/templates`（`back/app/project/views.py::get_templates_view`），
  返回 `{'success': True, 'data': [...]}`，数据来自 `back/app/project/services.py` 的单一来源常量 `TEMPLATES`。
- 每个模板字段：

  | 字段 | 含义 |
  |---|---|
  | `template_type` | 唯一标识（线性叙事 / 分支叙事 / 开放世界） |
  | `name` | 展示名 |
  | `description` | 一句话说明 |
  | `features` | 特性标签数组 |
  | `starter_scenes` | 建项目时自动铺设的起始场景（title / description / order_num） |
  | `recommended_variables` | 推荐变量（分支叙事=好感度、开放世界=线索数） |

- 三种模板脚手架：

  | template_type | 起始场景 | 推荐变量 |
  |---|---|---|
  | 线性叙事 | 开场 ×1 | — |
  | 分支叙事 | 开场(1) + 分歧点(2) | `affection` 好感度 |
  | 开放世界 | 序章(1) + 探索区域(2) | `clue` 线索数 |

- `create_project` 改为先 `db.session.flush()` 拿 `project_id`，再按模板创建起始场景。

> **重要约束**：脚手架**只建 `Scene`，绝不建 `ScriptContent`**。
> 原因：`test_audit_e2e.py` 断言「新建分支叙事项目后 `dialogue_count == 2`（手动创建两条对话）」，
> 若脚手架预置对话，该口径会被打破。

### 1.2 前端

- `front/src/api/project.ts`：新增 `TemplateMeta` 接口与 `getTemplates()`。
- `front/src/views/HomeView.vue`：
  - 「叙事模板」由原来的 `el-select` 改为**模板卡片**（名称 + 描述 + 特性标签 + 选中态图标）；
  - `onMounted` 调用 `loadTemplates()`，失败时回退到内置三模板，保证离线也能选。

## 2. 素材库引用计数

### 2.1 数据模型

新增 `back/app/models.py::ResourceReference`（新表由 `db.create_all()` 自动创建）：

| 列 | 说明 |
|---|---|
| `reference_id` | 主键 |
| `resource_id` | 被引用素材 FK `market_resources` |
| `user_id` | 引用者 FK `users` |
| `project_id` | 引用到的项目 FK `projects` |
| `created_at` | 时间 |

唯一键 `uq_resource_reference (resource_id, user_id, project_id)`：
同一素材被同一用户引用到同一项目**只算一次**；引用到多个项目则分别计数。

### 2.2 后端

- `get_market_resources` / `search_market_resources`：每条 resource 增加 `reference_count`，
  由 `_reference_count_map(resource_ids)` 用 `COUNT(...) GROUP BY resource_id` 一次性聚合，避免 N+1。
- `get_market_resource_detail`：返回 `reference_count`。
- 新增 `reference_resource(resource_id, user_id, project_id)`：
  - 校验项目归属（非本项目 → 404）；
  - 幂等：已存在返回 `already_referenced=True`，计数不叠加。
- 新增 `unreference_resource(resource_id, user_id, project_id)`：幂等删除。
- `delete_market_resource`：先删 `ResourceReference` 再删素材（级联清理）。

路由（`back/app/user/views.py`）：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/user/resources/<id>/reference` | body `{project_id}`，缺则 400 |
| DELETE | `/user/resources/<id>/reference` | query `project_id` |

### 2.3 前端

- `front/src/api/market.ts`：新增 `referenceResource` / `unreferenceResource`。
- `front/src/views/MarketView.vue`（纯 JS，禁 TS 语法）：
  - 卡片 meta 与详情统计展示「被引用」数（`Link` 图标，数字用 `formatDownloadCount` 缩写）；
  - 详情操作区新增「引用到项目」按钮 → 打开对话框，`getProjects()` 拉取自己的项目列表，
    选择后调 `referenceResource`，成功后刷新详情与列表以回显计数。

## 3. 项目导入导出

### 3.1 导出

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/project/project/<id>/export?format=json` | 完整项目包（默认） |
| GET | `/project/project/<id>/export?format=txt` | 纯文本剧本 |

- 两者均带下载头：`Content-Disposition: attachment; filename=...; filename*=UTF-8''...`
  （中文文件名经 `quote()` 编码，见 `back/app/project/views.py`）。
- JSON 包顶层键：
  `format / version / exported_at / project / characters / avatars / scenes / script_contents / variables / effects / branches / endings`。
- TXT 剧本格式：

  ```text
  《标题》
  类型：科幻    叙事模板：分支叙事

  # 场景 1：开场
  故事起点……
  角色名：台词
  （描述）
  【选择】
  ```

- 非所有者导出 → 404。

### 3.2 导入

- `POST /project/project/import`，body 为项目包 JSON，成功返回 **201** + `project_to_dict`。
- 校验：`genre ∈ GENRES`；`template_type` 非法则**回退线性叙事**；缺标题/类型 → 400。
- 重建顺序：角色 → 立绘 → 场景 → 变量 → 对话(`ScriptContent`) → 数值变化(`content_effects`) → 分支 → 结局；
  各表按**原 ID 建立映射**（旧 id → 新 id）后再连边，避免外键串位；最后 `update_project_word_count()` 重算字数。

> **关键设计**：导出包**顶层不含 `project_id`**。
> 因为 project 蓝图 `before_request` 会用 `_project_id_from_request()` 从 URL/body 里找项目 id，
> 若 body 顶层带 `project_id`，导入会被误判为「操作既有项目」而触发归属校验 → 404。

### 3.3 前端

- `front/src/api/project.ts`：新增 `exportProjectBundle` / `exportProjectText` / `importProject`。
- `front/src/views/HomeView.vue`：
  - 项目卡片右上角「导出」下拉（导出 JSON 包 / 导出剧本 TXT），
    用 `URL.createObjectURL` + 隐藏 `<a>` 触发浏览器下载；
  - 头部新增「导入项目」按钮 + 隐藏 `<input type="file" accept=".json">`，选文件 → `importProject` → 刷新列表。
