# AIGCNovel 交接提示词：剩余任务 + 全量测试方法

> 用法：把下面「提示词正文」整段复制给下一个 AI 代理（或作为你自己的执行清单）。
> 目标：在不重做已完成功能的前提下，继续补齐剩余能力，并用统一方法回归整个项目。

---

## 提示词正文

```text
你是 AIGCNovel 项目的接手开发者。项目路径 D:\AIGCNovel，前后端分离：
- 后端：Flask，入口 back/manage.py，端口 8088，虚拟环境 back/.venv
- 前端：Vue3 + TypeScript + ElementPlus + Vite，目录 front
- 数据库：MySQL aigc（root/****，见 back/.env），Redis 可选（Docker 6380，未启动时自动降级）
- 本地模型：Ollama qwen2.5:7b；本地 SD / MusicGen 权重在 back/.models

先读这些文档再动手：
- docs/Bug清单.md（历史 bug + 第4~6批修复状态）
- docs/第4批-运行时审计与安全加固.md
- docs/第5批-分支节点与样式修复.md
- docs/第6批-功能取舍与阅读器体验.md（做/不做清单 + 已完成项）
- .workbuddy-ai/memory/MEMORY.md（运行约定与踩坑）

==================================================
一、当前已完成（不要重做）
==================================================
1. 基础创作闭环：项目/角色/立绘/场景/对话/分支 CRUD
2. AI：文本（Ollama/DeepSeek）、图像（通义/本地 SD）、音乐（MusicGen）、配音（火山 TTS）
3. RAG 人设库、多轮记忆续写、FSM 剧情校验
4. 安全：全局 JWT 校验 + 项目归属校验（app/security.py、project before_request）
5. 播放器：设置（文字速度/自动间隔/音量/全屏）、多存档+自动存档+云存档、
   跳过已读+完整回想、移动端触控、变量/好感度、条件分支、结局判定与收集
6. 工程：SECRET_KEY 默认值告警、图片懒加载、副标题对比度修正、100vw 溢出修复、
   反斜杠静态路径修复、级联删除补全

==================================================
二、剩余任务（按优先级，逐个做、逐个测）
==================================================
【P0 先做】
1. Redis/Celery 异步链路复测

   - 启动 worker：cd back && .\.venv\Scripts\python.exe -m celery -A celery_app worker -l info -P solo --concurrency=1
   - 断言：/ai/health cache.connected=true；test_batch12_e2e.py 的 2 个跳过项变成实测；
     同步/异步结果一致，缓存命中不重复落库。
2. CI + 类型检查
   - npm run build 目前会因 vue-tsc 的 ~75 个历史类型错误失败，日常只用 npx vite build。
   - 逐个修类型错误，目标：npm run build 通过；加 GitHub Actions 跑后端 pytest/脚本 + 前端 build。
3. 性能
   - 当前 bundle ~2.4MB、logo 1.98MB、登录背景 4.1MB。
   - 做路由懒加载/手动 chunk、压缩图片为 WebP、播放器/列表图片懒加载；目标首屏 <1.5MB。

【P1 产品深度】
4. CG 图鉴：给资源加 CG 标记 + 解锁表 + 鉴赏页（依赖结局解锁体系，可复用 ending_unlocks 思路）。
5. 节点级剧情图：当前「剧情树」按场景聚合且只读；做 content-level 节点、拖拽连线、条件编辑。
6. 演出指令：立绘位置/表情/淡入淡出、背景转场、音效；建议在 script_contents 加演出 JSON 或新表。
7. 模板中心 + 素材库 + 导入导出：线性/分支/开放世界模板；素材引用计数；JSON/TXT 导入导出，Ren'Py 导出后置。

【P2 平台化，非当前工具定位，做前先确认】
8. 发布审核、作品详情页、分享/二维码、更新日志
9. 评论/点赞/收藏/关注/排行榜
10. 真实订单/分成/限免；不做就明确标注「演示支付」
11. 创作者数据看板：完读率、分支选择分布、留存

【明确不做/暂缓】
- 多语言、多人协作、版本历史
- 移动端原生壳
- 为「平台感」堆空壳功能（评论/支付/审核没有后端支撑就不要做 UI）

==================================================
三、全量测试方法
==================================================
0) 环境准备
   - 关闭代理干扰：所有本地请求设置 NO_PROXY=127.0.0.1,localhost
   - 后端：cd D:\AIGCNovel\back && .\.venv\Scripts\python.exe manage.py
     （日志写 %TEMP%，不要放 back/ 下；默认 use_reloader=False）
   - 前端：cd D:\AIGCNovel\front && npx vite --port 5175 --strictPort
     （5173 可能被另一个项目占用，不要盲用）
   - 测试账号：celerytest / Test123456（user_id=4）；项目 7「妄」属于 user_id=1
   - 生成测试 token（用户1，8小时）：
     cd D:\AIGCNovel\back
     .\.venv\Scripts\python.exe -X utf8 -c "import sys;sys.path.insert(0,r'D:\AIGCNovel\back');from datetime import datetime,timedelta,timezone;import jwt;from config import Config;print(jwt.encode({'identity':1,'role':'STUDENT','userName':'fixture_1','exp':datetime.now(timezone.utc)+timedelta(hours=8)},Config.SECRET_KEY,algorithm='HS256'))"
     记作 $TOKEN；请求头必须同时带 Authorization: Bearer $TOKEN 和 X-User-Id: 1（两者不一致会 403）。

1) 基础回归（每次改完必跑）

5) 测试数据清理

   - 确认：项目列表只剩「妄」；project_variables/content_effects/save_slots/read_records/endings/ending_unlocks 均为 0。
   - 清理临时用户：username LIKE 'audit_other_%'。
   - 历史路径异常可跑 fix_paths.py（幂等）。

==================================================
四、必须遵守的坑
==================================================
- 鉴权：Authorization Bearer + X-User-Id 必须一致；token 过期会 401。
- 前端 5173 可能是别的项目，本系统用 5175。
- 纯 JS 的 <script setup>（如 ExportProject.vue）不能写 TS 语法，ref<any> 会让播放器白屏。
- el-dialog 会 teleport 到 body，scoped :deep 选不中，弹窗样式用非 scoped 全局样式。
- 组件嵌在 tab 里不要用 100vw，会横向溢出 98px。
- 静态资源路径落库必须 POSIX；Windows os.path.join 会产生反斜杠，拼 URL 会坏。
- create_app 里 db.create_all() 只建缺失表；改已有表结构要手工 SQL/迁移。
- 删除顺序：分支边/数值变化/已读/存档/结局 → 对话 → 场景 → 变量 → 项目。
- 改 Python 后必须重启后端；前端 Vite HMR 自动更新。
- 中文文档不要用 PowerShell Get-Content|Set-Content 改写（会 GBK/UTF-8 乱码），用 edit/write 工具。
- 不要提交 .env/密钥；SECRET_KEY 默认 ailab 只用于本地，生产必须换随机值。

==================================================
五、交付标准
==================================================
每完成一项：
1. 代码改动 + 对应测试（API 或 UI）。
2. 更新 docs/Bug清单.md 与 docs/第7批-*.md（新建批次文档）。
3. 回归：npx vite build；test_audit_e2e.py 36/0；相关专项脚本通过。
4. 清理测试数据，确认项目 7 未被污染。
5. 不把「暂缓/不做」项偷偷做成半成品 UI。
```
