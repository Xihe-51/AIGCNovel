# 第 6 批 · 功能取舍与阅读器体验

> 目标：按 P 级判断「哪些必须做、哪些不做」，然后逐项实现、逐项测试。
> 本文先定取舍，后续每完成一项就在文末更新状态。

---

## 一、取舍结论

### ✅ 做（按顺序）

| 顺序 | 项 | 级别 | 工作量 | 为什么必须做 |
|---|---|---|---|---|
| 1 | 阅读器设置：文字速度 / 自动间隔 / BGM 音量 / 语音音量 / 全屏 | P0 | S | 玩家一进作品就会找设置；没有它不像"能玩的作品" |
| 2 | 多存档位 + 自动存档 + 云端存档 | P0 | M | 现在只有单个 localStorage，换设备/清缓存即丢，是硬伤 |
| 3 | 跳过已读 + 完整回想（backlog） | P0 | M | 互动阅读的阅读器标配，直接决定二周目体验 |
| 4 | 移动端触控：点击继续 / 上滑回想 / 横屏 | P0 | S | 这类作品大量在手机上看；现在只有鼠标点击 |
| 5 | 变量系统（好感度/数值/开关）+ 节点数值增减 | P1 | L | 没有变量，分支只是"选哪句"，做不了养成/好感度 |
| 6 | 条件分支 UI + 播放器条件判断 | P1 | M | `branch_conditions` 已有字段但前后端都没用，属于半成品 |
| 7 | 结局判定 + 结局收集 | P1 | M | 变量做完后自然需要"达成哪个结局"，也是留存点 |
| 8 | 工程快速项：SECRET_KEY 启动校验、图片懒加载、明显低对比度修正 | P4 | S | 成本低、收益直接，顺手做 |

### ❌ 不做 / 暂缓（附理由）

| 项 | 决定 | 理由 |
|---|---|---|
| CG 图鉴 | 暂缓 | 需要先有「CG 标记 + 解锁表 + 鉴赏页」，当前连 CG 资源分类都没有；等结局系统落地后再做 |
| 立绘位置/转场/特效等演出指令 | 暂缓 | 属于表现力增强，工作量大；当前"背景 + 立绘 + 对话 + 分支"已能完整叙事 |
| 节点级拖拽剧情图 | 暂缓 | 现有「选择项下拉配分支」已能表达分支；拖拽编辑器是体验升级，不是功能缺口 |
| 模板中心 / 素材库 / Ren'Py 导入导出 | 暂缓 | 属于生产力工具，当前项目规模（单项目几十场景）还用不上 |
| 评论 / 点赞 / 收藏 / 关注 / 排行榜 | 不做 | 这是平台运营能力，需要用户量与审核体系；现在做只会是空壳 |
| 发布审核 / 真实支付 / 分成 | 不做 | 同上；当前定位是创作工具 + 预览，支付保持"演示"并明确标注即可 |
| 多语言 / 多人协作 / 版本历史 | 不做 | 与当前单作者、中文作品定位不符 |
| `vue-tsc` 75 个类型错误 | 暂缓 | 不影响运行与构建，单独排期；先把功能闭环做完 |
| 全面无障碍改造 | 只做明显项 | 只修低对比度副标题等肉眼可见问题，不做完整 WCAG 审计 |

## 二、实施记录

> 每完成一项，补充「改了什么 / 怎么测 / 结果」。

### 1. 阅读器设置（P0，已完成）

- 设置弹窗：文字速度（瞬间/快/正常/慢）、自动播放间隔（1-6s）、BGM 音量、语音音量、全屏。
- localStorage 持久化；音量实时生效；文字速度切换后当前句按新速度重排。
- 逐字显示：点击对话框第一次先补全文字，再点才进入下一句；自动播放等文字显示完才计时。
- **顺带修掉一个 CSS 根节点类名笔误**：模板是 `export-project-project-container`，样式表是
  `export-project-container`，导致播放器根容器样式（100vw/100vh/overflow）从未生效。

**测试（CDP 真实点击）**

```text
逐字显示        t0=41 → t+0.35s=47（慢速生效）
点击补全        138 字立即完整，之后不再增长
设置弹窗        5 行、3 个滑块、1 个开关
改文字速度      下拉选「瞬间显示」→ localStorage textSpeed=0
恢复默认        localStorage 回到 textSpeed=2
BGM 音量        页面 audio.volume = 0.6（与设置 60% 一致）
```

### 2. 多存档位 + 自动存档 + 云端存档（P0，已完成）

- 新增 `save_slots` 表（user_id + project_id + slot 唯一），`slot=0` 自动、`1-3` 手动。
- 接口：`GET/PUT/DELETE /project/saves/<project_id>/<slot>`、`GET /project/saves/<project_id>`。
- 播放器：存档面板（4 个位）、手动保存/读取/删除；每次推进对话 1.5s 后静默写自动存档。
- 归属校验：只有项目所有者能读写自己的存档（他人 404）。
- 云端失败时回退到原来的 localStorage 单档。

**测试**

```text
自动存档      推进对话后 slot0 出现（summary=当前场景 · 当前句）
手动保存      存档 1 写入成功，API 列表 2 条
读取          推进到下一句后读取存档 1，正文恢复为保存时那句
删除          存档 1 删除成功，slot0 保留并更新
越权          user_id=4 访问项目 7 的存档 → 404
```

### 3. 跳过已读 + 完整回想（P0，已完成）

- 新增 `read_records` 表（user_id + project_id + content_id 唯一）与三个接口：
  `GET/POST/DELETE /project/reads/<project_id>`。
- 播放器显示某句时自动标记已读（1.5s 防抖批量上报，失败写 localStorage）。
- 设置里新增「跳过已读」开关：开启后连续跳过已读节点，直到未读或遇到「选择」节点。
- 回想面板从「当前场景」改为**全局历史**：显示场景名；选择分支会额外记录所选文案。

**测试（CDP 真实点击）**

```text
首次显示        首句「阳光倾泻…」，API 已读 content_ids=[9]
开启跳过已读    刷新后 currentId=10，正文变为「王医生，我真的没病…」，skipped=true
完整回想        刷新后 1 条（开场）；快进到下一场景并推进后 3 条，场景集合
                ["开场","第一慕下"]，跨场景生效
```

### 4. 移动端触控（P0，已完成）

- 竖屏（宽度 < 900 且 portrait）显示「建议横屏体验」提示，可关闭（sessionStorage 记忆）。
- 触控手势：**上滑打开完整回想**、**下滑关闭回想/隐藏 UI**；点按继续。
- 滑动后会抑制浏览器补发的 click，避免"滑一下跳两句"。
- 移动端触控目标放大：功能按钮 40×40、设置按钮 44×44；对话框字号 16px、选项按钮加高。
- `touch-action: manipulation` + 去掉 tap 高亮；音频解锁增加 touchstart 监听。

**测试（CDP 390×844 + 真实 touch 事件）**

```text
竖屏提示        rotateHint=true
触控目标        func-btn 40×40，settings-btn 44×44，dialogue 16px
上滑            history=true
下滑            先关回想（history=false，对话框仍在）
再下滑          隐藏 UI（dialogueVisible=false，showBtn=true）
点按            正文从「阳光倾泻…」变为「王医生，我真的没病…」
```

### 5. 变量系统（P1，已完成）

- 新增 `project_variables`（变量定义）与 `content_effects`（节点数值变化）两张表。
- 接口：
  - `GET/POST /project/variables/<project_id>`、`PUT/DELETE /project/variables/<project_id>/<variable_id>`
  - `GET /project/effects/<project_id>`、`GET/PUT /project/effects/<project_id>/<content_id>`
- 编辑器：
  - 项目页新增「变量」tab：展示名 / 变量名 / 初始值 / 范围 / 说明，支持新建、编辑、删除。
  - 场景编辑每条内容新增「数值变化」：选变量 + 填 delta，可加多条、单独保存。
- 播放器：
  - 启动加载变量定义与全部 effects；到达节点时按 `initial_value + delta` 累加，并按 min/max 夹紧。
  - 右上角新增「当前状态」面板；存档 `state_json.variables` 会带上运行时数值，读档恢复。
  - 重新开始时变量回到初始值。
- 删除链路补全：删对话/场景/项目会清理 `content_effects`；删项目会清理变量定义。

**测试**

```text
API            创建/重名/非法变量名/更新/删除、effect 保存与越权校验全部符合预期
变量 tab       表格显示「林瑶好感度 affection_lin 10 0~100」
新建变量       填表保存后 API 出现 test_affection（初始值 3）
节点数值变化   打开场景即回显「林瑶好感度」；delta 5→7 保存后 API 返回 7
播放器         初始 10 + 节点 +5 = 15；状态面板显示「林瑶好感度 15」
存档/读档      state.variables={"affection_lin":15}；推进后读档仍为 15（未重复加）
级联删除       带变量/数值变化的项目删除 200
```

### 6. 条件分支（P1，已完成）

- 条件格式：`{ "variable": "affection_lin", "op": ">=", "value": 50 }`；空表示无条件。
- 后端 `branch_service` 统一校验：运算符只能是 `> >= < <= == !=`、变量必须属于该项目、比较值必须是整数；
  创建/更新/批量写入三条路径都校验。
- 编辑器：每个选项下方新增条件行（变量 / 运算符 / 比较值），保存时写入 `branch_paths.conditions`。
- 播放器：`currentChoices` 按变量当前值过滤；不满足条件的选项直接隐藏；
  如果所有选项都被隐藏，则允许按线性剧情继续，不会卡死。
- 变量改名会同步更新分支条件里的变量名；删除变量会清空引用它的条件，避免死条件。
- 删除链路补充：删对话/场景/项目时一并清理 `read_records`、`save_slots`、`content_effects`。

**测试**

```text
API            合法条件 200；非法运算符/不存在变量 400
播放器 10<50   选择节点只显示「沉默」
播放器 60>=50  显示「打招呼」「沉默」两个选项
点击跳转       点「打招呼」→ 正文「她开心地笑了。」
编辑器回显     2 个选项，条件行显示「林瑶好感度 ≥ 50」
编辑器保存     条件值 50→5，API 返回 conditions.value=5
```

### 7. 结局判定与收集（P1，已完成）

- 新增 `endings`（标题/描述/触发节点/条件列表）与 `ending_unlocks`（用户+结局唯一）。
- 接口：结局 CRUD、`POST /project/endings/<pid>/<eid>/unlock`；列表带当前用户 `unlocked` 状态。
- 编辑器：项目页新增「结局」tab，可新建/编辑/删除结局；触发节点从剧情图节点中选择；
  条件行复用变量 + 运算符 + 比较值（全部成立才触发）。
- 播放器：到达触发节点且条件成立 → 弹结局页（标题/描述），并调用 unlock 记录；
  同一周目不重复弹；存档 `state_json.triggeredEndings` 会带上已触发结局。
- 删除链路补全：删对话/场景/项目会清理引用节点的结局与解锁记录。

**测试**

```text
API            创建结局 200；非法触发节点/不存在变量 400
播放器         好感度 10 >= 5 → 结局页「林瑶的告白 / 你们在一起了。」
解锁记录       API unlocked=true；编辑器「结局」tab 显示「已解锁」
条件不满足     改成 >=50 后重进 → 不弹结局，正文停在「她答应了。」
级联删除       带结局/解锁/变量的项目删除 200
```
